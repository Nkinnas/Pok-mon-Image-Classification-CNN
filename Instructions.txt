Download zip and unzip

get images from: https://www.kaggle.com/datasets/mikoajkolman/pokemon-images-first-generation17000-files/code/data

unzip those images and place them in the "Pokemon_images" file. (it is empty right now)

run make_splits.py

run train.py

run predict.py  (make sure before running this that you have placed the image you want to classify inside of "Image_to_predict") (since this is only for the first generation of pokemon, the image should be of one of those 151 pokemon)

You will have to adjust paths in the scripts "train.py" and "make_splits.py" and "predict.py"
